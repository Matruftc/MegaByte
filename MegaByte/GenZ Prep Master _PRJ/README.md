# GenZ Prep Master by MegaByte

High-yield technical, coding, programming and behavioral interview preparation, with 200 questions across four tracks.

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Start the app:
   `npm run dev`

Open the local URL printed by Vite. The MegaByte landing page links to this project from `GenZ Prep Master _PRJ/`.
