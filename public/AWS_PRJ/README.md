# MegaByte AWS Academy

A static, responsive AWS foundations academy with no build step or server dependency.

## Open locally

Open `index.html` in a browser or serve the repository with any static file server. The academy includes learning paths, a service map, practice quizzes, flashcards, search, and locally saved progress.

## Progress and privacy

Theme preference, completed lessons and quiz activity are stored in this browser's local storage. The academy does not require an AWS account or connect to AWS services.

## Content scope

The lessons introduce cloud concepts and common AWS services. AWS services, features, quotas and prices can change; confirm current details in AWS documentation before production use.
