# MegaByte Java Academy

Learn Java by running it with the MegaByte Java Academy.

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Optionally set `GEMINI_API_KEY` in `.env.local` to enable Gemini-powered features
3. Run the app:
   `npm run dev`

Open `http://localhost:3000` to start learning. The MegaByte landing page links to this project at `JAVA_PRJ/`.
